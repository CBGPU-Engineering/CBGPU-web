# Visual reference review

All 23 references were downloaded and decoded. The original Tier 1 images
and readable 1100 px analysis views of Tiers 2–6 were visually inspected.
The reference files live outside the repository. The preview serves its own
assets and separately licensed photographs.

Hanwik governs the overall look. Servly informs the depth of the navigation,
search and icons. The other tiers give feature-specific layout examples.
